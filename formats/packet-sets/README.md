# Packet Set Listings Format

The website uses a hardcoded JSON file to list packet sets (a named group of packet PDF URLs).

## Canonical data

- `apps/website/frontend/src/features/packets/data/packet_sets.json`

## Canonical generator

- `scripts/generate_packets_from_s3.py`

This folder provides a small schema doc + an example entry + a wrapper script for convenience.
