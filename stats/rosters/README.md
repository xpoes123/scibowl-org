# Roster Artifacts (`/stats/rosters`)

This folder contains small helper artifacts used by MoSS to quickly discover which tournaments have roster files.

## Files

- `index.json`
  - Generated index of tournament slugs that have a `stats/<slug>/field.json` roster file.
  - This file is regenerated by the repo sync script (see `scripts/sync-stats.mjs`).

## Roster file format

Each tournament roster lives at:

- `stats/<tournament_slug>/field.json`

Schema (v1):

```json
{
  "format": "moss_field_roster",
  "version": 1,
  "tournament": { "slug": "example", "name": "Example" },
  "teams": [
    { "name": "Team A", "players": ["Player 1", "Player 2"] },
    { "name": "Team B", "players": ["Player 3", "Player 4"] }
  ]
}
```

Notes:

- `teams[].players` order matters: MoSS will default the first four players to Active and the rest to Bench when autofilling a team.
- Uploading a roster file in MoSS expects the same `field.json` schema.
